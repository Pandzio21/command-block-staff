# Controls

Everything is rebindable under **Options → Controls → Command Block Staff Addon**. Defaults:

| Key | Action |
|-----|--------|
| ++z++ + scroll | Change ability (1–6) |
| ++left-alt++ | Change the current ability's mode |
| {{ "`" }} + scroll | Adjust the current ability's setting |
| ++v++ | Open the current ability's menu |
| ++tab++ | Build modifier (paint, shape cycle, summon, easy stairs) |
| ++ctrl++ | Pick Block (eyedropper) in Placement |
| ++x++ | Un-electrify what you're aiming at |
| ++c++ | Choke a mob held in the beam (hold) |
| ++u++ | Undo the last command-ability action |
| ++g++ | Mount / dismount the staff |

## Mouse

Right-click is the main action, left-click the secondary or quick-chooser. **Pick Block + right-click** is
an eyedropper in every placement mode — it's a real binding, so if you've moved sneak onto Left Ctrl you can
move the picker somewhere else instead of losing one of them.

The **build modifier** (++tab++) is a real key, not Shift — building doesn't make you crouch. Shift is still
used where crouching makes sense: revealing electrified things, whitelisting a mob into your shield,
forcing a command target.

When a mode has an extra action available, it prints a one-line hint at the top of the screen. Those hints
name **your** keys, including your sneak bind — rebind sneak and the hints follow it. Every Shift action in
these docs means "your sneak key", whatever that is.

Exact bindings are on each ability's page.
