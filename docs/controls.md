# Controls

All of it is rebindable under **Options → Controls → Command Block Staff Addon**. Out of the box:

| Key | Action |
|-----|--------|
| ++z++ + scroll | Switch ability (1–6) |
| ++left-alt++ | Switch the current ability's mode |
| {{ "`" }} + scroll | Tune the current ability |
| ++v++ | Open the current ability's menu |
| ++tab++ | Build modifier — paint, cycle shapes, summon, easy stairs |
| ++ctrl++ | Pick Block (eyedropper) in Placement |
| ++x++ | Un-electrify what you're aiming at |
| ++c++ | Choke whatever you've got in the beam (hold) |
| ++u++ | Undo the last command-ability action |
| ++g++ | Get on / off the staff |

None of these do anything unless you're actually holding the command-block staff, so they won't interfere
with normal play.

## Mouse

Right-click is the main action, left-click the secondary or the quick-chooser. **Pick Block + right-click**
is an eyedropper anywhere in Placement — it's a real binding, so if you've moved sneak onto Left Ctrl you
can move the picker somewhere else rather than lose one of them.

The **build modifier** is its own key rather than Shift, so building doesn't crouch you. Shift is still
used where crouching makes sense: revealing what you've electrified, whitelisting someone into your shield,
forcing a command target.

When a mode has something extra available, you get a one-line hint at the top of the screen. Those hints
name **your** keys, sneak included — rebind it and they follow. Anywhere these docs say Shift, they mean
your sneak key, whatever that is.
