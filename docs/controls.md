# Controls

All of it is rebindable under **Options → Controls → Command Block Staff Addon**. Out of the box:

| Key | Action |
|-----|--------|
| ++z++ + scroll | Switch ability (1–6) |
| ++left-alt++ | Switch the current ability's mode |
| {{ "`" }} + scroll | Tune the current ability |
| ++v++ | Open the current ability's menu |
| ++tab++ | Build modifier — paint, cycle shapes, summon, easy stairs |
| ++x++ | Un-electrify what you're aiming at |
| ++c++ | Choke whatever you've got in the beam (hold) |
| ++u++ | Undo the last command-ability action |
| ++g++ | Get on / off the staff |

None of these do anything unless you're actually holding the command-block staff, so they won't interfere
with normal play.

## Quickbinds

Three things you'll want mid-fight, on their own keys — **no need to scroll to the ability first**. They
work from whatever ability you happen to have out, and they're all straight on/off toggles.

| Key | Action |
|-----|--------|
| ++h++ | Shield on / off |
| ++j++ | Defense Wall on / off |
| ++k++ | Platform on / off |

The **wall** stands and follows your aim exactly as it does when you hold right-click in Defense Wall —
you just don't have to hold anything. Turning it off tears it down, same as a left-click would.

The **platform** paves itself under you as you walk, so you can bridge or scaffold hands-free. It uses
your selected Placement block, and it only ever fills air — it won't chew through anything already there.

- **{{ "`" }} + scroll** resizes it: **3 to 5** blocks wide.
- **Build modifier** (++tab++) switches the scroll over to **depth**, **1 to 3**. Depth goes *downward*
  from the block you're standing on, so a thicker platform hangs below the surface you walk on rather
  than rising up around your feet.

Sizes stick, so once you've set it up, ++k++ builds the same platform every time.

## Mouse

Right-click is the main action, left-click the secondary or the quick-chooser. **Middle-click** is an
eyedropper anywhere in Placement — it picks the block you're aiming at, at the staff's range, without
swapping the staff out of your hand the way vanilla's pick-block would.

The **build modifier** is its own key rather than Shift, so building doesn't crouch you. Shift is still
used where crouching makes sense: revealing what you've electrified, whitelisting someone into your shield,
forcing a command target.

When a mode has something extra available, you get a one-line hint at the top of the screen. Those hints
name **your** keys, sneak included — rebind it and they follow. Anywhere these docs say Shift, they mean
your sneak key, whatever that is.
